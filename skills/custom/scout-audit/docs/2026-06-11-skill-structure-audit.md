# Scout-Audit 技能主文件结构审计

> 本文件作为 `scout-audit` 技能目录内的本地审计基线与验收参考。
> 原始审计结论来源: `docs/superpowers/plans/2026-06-11-skill-structure-audit.md`
> 说明: 为避免主文件继续承担治理说明，本文件只保留本次结构治理必须追踪的结论摘要与验收要点。

## 结论摘要

- `SKILL.md` 之前同时混入了编排合同、字段级 schema、模板细节、脚本说明和治理内容，导致主文件职责越界。
- 结构治理的重点不是新增业务规则，而是把主文件收紧回入口级 contract，把专项内容迁回专项文件。

## 关键问题

| 优先级 | 问题 | 风险 |
| ------ | ---- | ---- |
| P0 | 主文件职责越界 | 形成双份真相，后续极易漂移 |
| P0 | 交付链细节内嵌主文件 | 脚本接口调整时同步成本高 |
| P1 | `joint` 模式细节展开过深 | 主文件难以快速扫描，边界不清 |
| P1 | 字段 canonical 约束散落主文件 | schema 失去单点权威 |
| P2 | 治理性内容与调用入口混写 | 影响技能主入口阅读效率 |

## 目标状态

- `SKILL.md` 只回答:
  - 什么时候用
  - 什么时候不能用
  - 正式审核主链怎么走
  - 什么情况下必须停止
- `contracts/` 承接流程专项合同
- `schemas/` 承接字段与结构定义
- `templates/` 承接固定输出与报告/日志格式
- `scripts/README.md` 承接脚本接口说明
- `docs/` 承接治理型维护说明

## 验收要点

- `SKILL.md` 已收紧到入口级 contract
- 同一约束只保留一个权威落点
- `docs/sync-matrix.md` 已覆盖新增权威文件
- 结构治理完成后，最小回归应保持通过
