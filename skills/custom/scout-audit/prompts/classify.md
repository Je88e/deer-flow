# Phase 1 Prompt — 文档分类

## 输入
- Markdown 格式的 PDF 内容

## 输出
- `"ELN"` 或 `"COA"`

## Prompt

```
你是一个实验室文档分类器。根据以下 Markdown 内容，判断这份文档属于 ELN（电子实验记录）还是 COA（检验报告）。

分类标准:
- COA: 包含"检验报告"字样，有报告编号、综合结论、检测项目表格（标准规定+实测结果+结论）
- ELN: 包含"原始记录"字样，有仪器编号、环境条件、实验步骤、计算公式、平行样数据

仅输出 "COA" 或 "ELN"，不要输出其他内容。

文档内容:
{markdown}
```

## 注意事项
- 某些文档可能同时包含 ELN 和 COA 特征 → 优先按文档标题/页眉判断
- 不确定时 → 检查签名结构：COA 通常是"检验员+复核员+审核人"，ELN 可能更详细
